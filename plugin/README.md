# Touchline Football — DSH 足球悬浮插件

MIT 开源插件。为 DeepSeek Harness 提供可拖动的 2D 比赛小窗、比分胶囊、关键事件记录和本地逐帧回放。本项目以 DSH 插件为唯一正式交付物。仓库保留本地调试页面，供开发者验证渲染与数据，不提供独立网页版产品支持。

## 宿主要求

- Node.js 20+。
- DSH 宿主需支持 `dsh.bundle.patch`、`dsh.client`、`webServer.register`、`ctx.effect` 和 slots API。
- 使用 `shell.overlay` 与 `conversation.composer.dock` 两个插槽。
- React 及 JSX runtime 由宿主提供，不在插件中重复打包。

已在 Windows 的 DSH 0.2.2-rc.1 验证安装、挂载、合成回放和停用后重新启用；真实直播切换仍待有赛事时补验。尚未建立最低 DSH 版本兼容矩阵。

## 构建与安装

从项目根目录执行：

```sh
npm ci
npm run plugin:pack
```

产物为 `dist/dsh-plugin-touchline-<version>.tgz`。通过目标 DSH 版本的本地插件包安装入口导入此包；本项目不假定不同版本的安装命令一致。插件包名为 `dsh-plugin-touchline`，bundle patch 插入的行 ID 为 `web-ui-touchline`。启用后刷新 Web GUI；更新宿主侧代码后需重载插件行或重启宿主。

开发与验收也建议安装 `.tgz`，不要把源码目录以 `link:` 安装到宿主。本机 DSH 0.2.2-rc.1 的实际验收中，卸载链接插件清空了链接目标内容。每次更新先备份源码，构建新版本安装包，通过“插件 → 添加插件 → 安装第三方插件”输入 `.tgz` 的绝对路径，再启用插件；本机已验证直接安装新版本可更新同名包。切换安装来源后重启宿主以清除模块路径缓存。

## 配置

插件行配置支持：

```json
{ "source": "espn", "replayDir": "/absolute/path/to/replays" }
```

`source` 默认 `espn`。安装包不包含赛事或回放数据；使用回放时应显式指定 `replayDir`。默认路径仅适合源码目录开发。可在项目根目录运行 `npm run replay:demo` 生成合成演示，再把配置指向该项目的 `data/replay` 绝对路径。

## 操作

- 胶囊点击显示/隐藏小窗，箭头菜单选择直播或回放。
- 拖动标题栏移动小窗；尺寸按钮切换三档尺寸；日志按钮切换关键事件带。
- `Ctrl+Shift+X` 隐藏/恢复小窗和胶囊。
- 没有直播但存在本地回放时，胶囊仍可用于进入回放。
- 回放按连续时钟插值播放；隐藏页面或卸下小窗画布时暂停推进，恢复后继续。
- 缺失追踪坐标的对象会隐藏，球缺失时标题提示“球位置缺失”，不会用事件推演补球路。
- 回放底部可拖动进度，或跳转到上下半场、换人前后与终场；时间为追踪录像累计时间（含补时，不含中场休息）。
- v3 回放支持替补球员，片段里的换人关系依据追踪出入场区间推断，不代表官方换人事件。

## 发布前宿主验收

1. 安装后确认 `/api/touchline/health` 返回成功，小窗和胶囊正常挂载。
2. 验证直播轮询、换场、拖动、尺寸、事件带及老板键。
3. 直播切回放后等待至少两个轮询周期，确认回放球队不被直播响应覆盖，再切回直播。
4. 禁用插件后确认路由、插槽、样式和快捷键清理；重新启用后正常恢复。
5. 验证无直播、无回放及上游断网场景。

## 数据边界

直播正常轮询目标为 5 秒（不含上游自身延迟），失败时退避；底部显示事件推演与同步状态。无新坐标时停留在最后事件位置，球员保持有限的阵型调整。画面不是连续真实追踪；不能用这次同步优化承诺电视直播级实时性。

直播使用 ESPN 公开接口，球员位置由事件和阵型推演，不是实时光学追踪。MIT 许可覆盖本项目代码，不授予第三方赛事数据使用权。上游接口可能变化；发布包不包含赛事数据、下载样本或队徽文件。
