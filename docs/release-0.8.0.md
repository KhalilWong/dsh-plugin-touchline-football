# Touchline Football 0.8.0（预发布）

为 DeepSeek Harness 提供可拖动的足球比赛小窗、比分胶囊、关键事件和本地逐帧追踪回放。代码采用 MIT 许可，安装包不包含赛事数据。

## 安装

下载本次 Release 的 `dsh-plugin-touchline-0.8.0.tgz`，在 DSH“插件 → 添加插件 → 安装第三方插件”中输入下载文件绝对路径并启用。可使用 `SHA256SUMS-0.8.0.txt` 校验。内部包名保留 `dsh-plugin-touchline`。

已验证 Windows DSH 0.2.2-rc.1；其他宿主版本尚未建立兼容矩阵。已验证挂载、隐藏恢复、停用清理与重新启用。

## 功能和限制

- 默认 ESPN 公开接口提供赛程、比分和事件，无需付费数据源。
- 直播轮询目标 5 秒、失败退避、旧快照保护和球员/球运动约束。画面是事件推演，不是真实连续球员追踪；5 秒不代表实测端到端延迟。
- 本地追踪回放支持整场、换人、进度跳转、帧间插值、缺失坐标和独立播放时钟。官方 Metrica 样本整场及六次换人已本地验收，样本不随包分发。
- 无直播仍可进入本地回放；Ctrl+Shift+X 隐藏或恢复小窗和胶囊。

真实 DSH 已完成模拟流验收；正在进行的真实赛事仍待补验，公开数据接口可能延迟或缺失坐标，因此首次发行标记预发布。

回放需自行配置 `replayDir`，可用源码生成合成演示数据，或按文档获取官方开放样本。第三方数据适用其自身许可。独立网页仅用于开发调试。
