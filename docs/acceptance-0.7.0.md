## 边界

已验收官方第 1 场 CSV。转换器仍只接受第 1、2 场 CSV，不支持第 3 场 EPTS。没有官方事件时，模糊的多人同时进出不强配换人关系；球员仍按各自追踪身份与可用区间绘制。此实现不等于适配所有供应商的全场格式。
