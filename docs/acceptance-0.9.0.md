# 0.9.0 直播同步候选包验收

截至 2026-11-23，候选包已在本地构建。下列时间均为北京时间。

## 市场版及开发包实机观测

11 月 20 日在真实 DSH 观察了西悉尼流浪者对阿德莱德联、Rajasthan United 对 Chanmari。前一场覆盖中场到下半场，后一场覆盖小窗收起后的胶囊时钟更新。逐次采样条件和球场坐标记录见[开发计划执行记录](roadmap-1.0.0.md#090-执行记录)。

市场版 0.8.3 的独立采样在 17:33:46 首次读到 45′+8′，宿主在 17:34:06 首次被观察到显示该时钟。宿主收包和首次显示时刻缺测，这 20 秒不能作为插件延迟。开发计时包取得一次从响应体读取完成到胶囊布局更新的样本，约 1 ms。两项记录均未测量赛事现场到屏幕的耗时。

## 同一输入的安装包对照

在 Edge 中分别加载两个安装包的客户端。依次投递四个模拟详情响应，时钟从 1′ 逐次推进至 4′，主队比分依次为 0、1、0、2。初次绘制球场后收起小窗，继续观察胶囊。以响应体解析完成为起点，以 DOM 同时出现该次比分和时钟为终点。

| 安装包 | 首次显示 | 收起小窗后的三次更新 |
| --- | --- | --- |
| 0.8.3 | 4.3 ms | 收到全部三个响应，观察窗口内均未显示对应更新 |
| 0.9.0 | 45.3 ms | 0.7、0.6、0.2 ms，比分更正和时钟均可见 |

每个版本运行一轮。首次显示只有一个样本，无法据此比较启动性能。上述数字只覆盖客户端处理和 DOM 更新，不含网络轮询等待及显示器绘制。

## 确定性回归

- 比分先于位置事件到达时即时显示；迟到、重复事件和旧快照不回退比分，更新的官方比分可以下调。
- 半场、过期缓存及事件源异常时冻结位置。下半场开始但只收到上半场坐标时，显示等待本节位置的提示。详情最近同步时间和位置事件时钟分别展示。
- 选中场次从直播列表消失后继续请求该场详情，收到终场状态后保留官方比分和时钟，每分钟再检查一次更正。
- 类型检查、35 项单元测试、构建、打包白名单检查及 Edge 直播同步回归通过。模拟直播三次轮询间隔为 5006、5001、5001 ms。
- Edge 插件回归通过直播与回放往返、快捷键隐藏与恢复、卸载与重新挂载。Metrica 官方整场样本共 58,003 帧，六次换人、跨半场、暂停恢复和终场重播均通过，两组回归均未报告页面错误。

## 真实 DSH 安装与回放抽验

11 月 23 日，真实 Windows DSH 从本地压缩包安装，安装结果显示版本 0.9.0。点击「立即启用」后，已安装列表中插件开关开启。回到会话，胶囊显示「暂无直播」，场次菜单显示「正在直播 · 0」。原有三个本地回放条目可见。选择 Metrica 第 1 场整场样本后，小窗绘出球场和球员，小窗与胶囊同步从 0:07 推进到 0:15，点击暂停后显示播放按钮。

16:43 独立读取同一 ESPN 适配器，返回 43 场、直播 0 场，最早计划开球为 20:30。最终包的新半场位置提示、收起小窗后的直播更新和终场保留仍待有相应赛事时现场复核。

2026-11-24，0.9.0 阶段验收完成。上述待补场景已转入[发布前直播复验](roadmap-1.0.0.md#发布前直播复验)，由 1.0.0 候选包统一验证、修复并复测。
