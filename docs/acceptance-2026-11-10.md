## 修复与回归

原问题：没有直播时组件返回空内容，首次进入回放时 Canvas 才出现，但绘制 effect 没有重新启动，造成黑屏和时钟停在 0:00。

修复：绘制 effect 依赖实际 Canvas 可见条件，覆盖无赛事进入回放以及隐藏后恢复。版本升至 0.5.1。

- `npm run plugin:pack`：类型检查、6 项测试、插件构建和打包通过。
- `npm run check:plugin`：Edge 无头浏览器验证真实插件 React 组件在模拟宿主中的回放动画、老板键隐藏/恢复、卸载/重新挂载，无页面错误。此项不等同于真实 DSH 直播验收。
- CI 增加 Windows 浏览器回归任务；尚未运行远端 CI。

## 链接卸载问题与恢复

原 profile 使用 `link:` 指向本项目 `plugin/`。实际卸载时该目录内容被宿主安装管理流程清空。已从卸载前 tarball 恢复运行文件，并从本机开发记录恢复 TypeScript、CSS 和构建脚本；重建的客户端与卸载前 bundle 逐字节一致，6 项测试通过。恢复后才应用 0.5.1 修复。

恢复后的源码备份：`tmp/recovery/plugin-source-restored.tgz`（本地忽略目录，不随开源包发布）。当前安装为普通包目录，已改用 `.tgz`，README 记录避免源码链接安装。

## 0.5.2 补充验收

继续检查时，公开赛程仍为 57 场、0 场直播，真实直播切换继续待验。获得插件画面焦点后复测 `Ctrl+Shift+X`（含大小写键符投递）仍未观察到隐藏，尚未确定原因，没有据此修改快捷键实现。

发现并修复宿主缓存生命周期问题：原缓存及请求合并记录为模块全局，路由卸载后仍保留。0.5.2 改为每次启用独立缓存，停用时清空，迟到响应不能写入已销毁缓存，也不会污染重新启用的实例。已经发出的上游请求不强制中断，可完成原响应。

新增 3 项离线宿主回归（共 9 项通过）：

- 7 条路由全部移除，重新启用读取新数据。
- 停用前未完成的请求不能污染新实例的缓存。
- 同一实例的直播与赛程并发读取仍合并上游请求。

这些测试模拟 `webServer` 与数据源，不能替代真实宿主 HTTP 路由卸载检查。`npm run plugin:pack` 类型检查、9 项测试及 0.5.2 打包通过。

0.5.2 已通过宿主插件管理器安装并启用；desktop profile 指向新 tarball，安装目录 `index.js` 与本地源码 SHA256 一致。真实 DSH 胶囊恢复，菜单列出本地演示，选择后球场正常绘制，时钟推进至 0:12 / 0:13。此轮未再次执行完整卸载。
