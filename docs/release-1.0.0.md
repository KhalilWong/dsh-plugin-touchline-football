# Touchline Football 1.0.0

在 DSH 中查看足球比分、比赛事件和 2D 球场，支持本地整场追踪回放。

## 相比 0.8.3

- 比分、时钟与球场状态分别同步；事件数据中断时保留位置并继续更新比分，明确提示数据新鲜度。
- 统一 ESPN 主客队坐标方向，修复客队射门和球权转换的假性跳变。远距离位置修正使用淡变，死球和缺坐标时不持续虚构运动。
- 识别进球后的中圈开球传球，恢复双方半场站位；正确处理半场等待坐标、补时与终场时钟。
- 内置 30 秒合成演示，无需本地文件即可体验。整场回放支持六次换人样本、缺球区间、跨半场、跳转与重播，列表使用元数据缓存。
- 适配新版 DSH 的 owner 认证，修复胶囊菜单被小窗遮挡。

## 安装与更新

安装包为 **`dsh-plugin-touchline-1.0.0.tgz`**。在 DSH「插件 → 发现」搜索 `touchline`，核对作者 `KhalilWong` 和版本后安装；也可下载本 Release 的安装包，在 DSH 的第三方插件安装入口输入文件绝对路径。

内部包名与已有配置不变。升级后重启 DSH，以加载新的宿主数据源模块。市场索引同步可能晚于 GitHub 和 npm 发布；以实际显示的版本为准。

## 验证和数据边界

候选版已在 Windows / DSH 0.2.3-alpha.2 验证安装升级、访问检查、清理、真实直播及官方整场回放。42 项测试及直播、回放浏览器回归通过。自然直播观察与真实事件在 DSH 中的受控重放分别记录，详见[验收记录](acceptance-1.0.0-rc.1.md)。

直播为事件推演，球员位置不是真实连续追踪。免费公开接口可能延迟、缺失或合批返回动作；5 秒轮询不等于端到端延迟保证。官方样本、私人配置、凭据、日志和桌面截图均不随包分发。代码采用 MIT 许可，第三方数据适用自身条款。

附件包含插件安装包、开发源码归档、源码清单与 SHA256 校验文件。普通用户选择插件安装包即可。
